pi-cursor-style▏

Customize the pi input cursor: bar, underline, colored block, or the terminal's native caret. Switch instantly — no restart.

自定义 pi 输入框光标：竖条、下划线、彩色方块或终端原生光标，即时切换。

$ pi install npm:pi-cursor-style

Four styles switched live with /cursor-style — characters never move or get covered.

Four styles

One command each, applied on the next frame and saved automatically.

helloworld

block

The familiar shape, in any color. Character stays readable.

hello▏world

bar

A thin beam between characters. Nothing hidden, nothing shifted.

helloworld

underline

hardware

The VS Code look: your terminal's own caret, cell-free. Characters never move.

Everyday commands

Everything through /cursor-style — check status, switch style, change color.

CommandEffect
/cursor-styleShow current config
/cursor-style barSwitch style: block / bar / underline / hardware
/cursor-style color #ff5f00Any hex, 256-color index, theme:<token>, or "none"
/cursor-style hardwareEnables the terminal caret automatically; switching back disables it
